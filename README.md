# العميد للتشطيبات

موقع تعريفي لشركة تشطيبات: ملف واحد `index.html` (HTML + CSS + JS) بدون أي مكتبات.

## قبل النشر
- غيّر رقم الواتساب في أول السكريبت: `const WHATSAPP = "01021318789"`.
- عدّل رقم الهاتف والعنوان ومواعيد العمل في قسم "تواصل معنا".
- الأرقام في شريط الإحصائيات (سنوات الخبرة وغيرها) أمثلة، عدّلها لتطابق الحقيقة.
- لإضافة صور أعمالكم: استبدل خلفية `.g` بـ `background:url(images/1.jpg) center/cover`.

## النشر المجاني
GitHub Pages: Settings → Pages → Branch: `main` / root.
